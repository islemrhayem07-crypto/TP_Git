\# TP Git



Ce projet est réalisé dans le cadre du TP Git \& GitHub.



Objectifs :

\- Apprendre les commandes Git.

\- Créer un dépôt local.

\- Connecter Git à GitHub.

\- Apprendre à travailler avec les branches.

\## Deuxième étape



J'apprends à utiliser les commandes Git :

\- git add

\- git commit

\- git status

\- git log



\## Mise à jour du projet



Ce projet est hébergé sur GitHub.

Les modifications sont envoyées avec la commande git push.
